# Агент GitHub по команде владельца

Для проекта 387 выбираем стандартную интеграцию OpenCode через официальный GitHub App: она соответствует заданию Hexlet и использует отдельную авторизацию приложения для ответов и работы с репозиторием. Локальная сессия агента и среда GitHub Actions остаются разными окружениями; свежему раннеру потребуется тот же закреплённый набор скиллов и актуальные инструкции проекта. Решения согласованы в обсуждении `$grill-with-docs` 17 ноября 2026 года.

Вызов разрешён только аккаунту `skaffman41` командами `/oc` и `/opencode`; комментарии ботов не запускают модель. События комментариев ограничены `types: [created]`, недоверенные PR из fork не получают секреты. Публикация сессий отключена (`share: false`). Стандартная авторизация использует `contents: read`, `id-token: write` и `persist-credentials: false` у checkout; права приложения обеспечивают ответы и разрешённую публикацию.

Для учебного проекта выбираем бесплатную модель `opencode/glm-5.3-flash-free`, без использования учебного бюджета и дополнительных личных расходов. Текущие нулевые цены и поддержка инструментов подтверждены в [каталоге OpenCode](https://opencode.ai/inference/v1/models); [документация](https://opencode.ai/docs/console/models/#free-models) предупреждает об ограниченном сроке бесплатного предложения. Совместимость этой модели с закреплённым GitHub-адаптером требуется подтвердить реальным запуском. При недоступности модели, исчерпании квоты или отмене бесплатности запуск останавливается с понятным результатом, без автоматического перехода на платную модель. Ключ провайдера хранится только в GitHub Actions Secrets.

Обычные обращения работают только на чтение и ответ, без изменения рабочей копии. Отдельная команда `/oc publish <задача>` явно разрешает изменение файлов, push рабочей ветки и создание либо обновление PR; `/opencode` служит эквивалентной командой вызова. Это уточняет общие правила отдельных разрешений на push и PR для данного GitHub-режима. Merge по-прежнему требует отдельной команды. Стандартный адаптер автоматически публикует обнаруженные изменения вне управления модели, поэтому границу режима чтения необходимо обеспечить конфигурацией инструментов и чистотой рабочей копии, а затем проверить; одного указания в AGENTS.md недостаточно.

Предел одного запуска — 30 минут, не более одного активного запуска на Issue или PR. Новый комментарий не отменяет уже работающий запуск. Ограничение времени не заменяет ограничения расходов у провайдера.

Приёмка охватывает все пункты блока «Требования» [шага 2 Hexlet](https://ru.hexlet.io/projects/387/members/54793?step=2), включая workflow в основной ветке, доступ скиллов на свежем раннере, описание в README и актуальные команды в AGENTS.md. Нужны два реальных прогона: ответ в Issue с правильными трекером, доступными скиллами и командой проверок; затем по отдельной команде публикации — небольшое дополнение README и PR. Результаты подтверждаются ссылками на ответы, Actions и PR; согласование дизайна само по себе не подтверждает выполнение требований.

## Замена модели — 18 ноября 2026

Первоначальный выбор GLM-5.3-Flash Free выше сохраняет историю решения от 17 ноября. После её [снятия OpenCode с бесплатного предложения 18 ноября](https://opencode.ai/docs/console/models/#deprecated-models) владелец явно разрешил замену на `opencode/deepseek-v4.1-flash-free` и отдельный bootstrap PR. [Согласованный scope](https://github.com/skaffman41/ai-for-developers-project-387/issues/28#issuecomment-6975155706), новая baseline — [план v3](../plans/pr-review-part1/v3/clarification.md).

Текущий [каталог OpenCode](https://opencode.ai/inference/v1/models) подтверждает tools и нулевые input/cache-read/output цены DeepSeek. Выбран один закреплённый ID для всех режимов агента и независимых ревьюеров. Подготовка каждого запуска заново проверяет эти условия и останавливается при их нарушении; платного fallback нет. Runtime 1.19.6, авторизация и права сохраняются. Конфигурационные проверки без inference не заменяют живой прогон GitHub после отдельной команды merge bootstrap в main.
