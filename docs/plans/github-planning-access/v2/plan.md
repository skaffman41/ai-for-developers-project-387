# Закреплённая версия при запуске GitHub-агента

Основание: поручение полностью завершить шаг 3 и исправить упавший action в #12. PR16 исправил авторизацию трекера. Живые запуски 44133018051 и 44133077036 снова упали до модели в Get opencode version: официальный action безусловно делает неавторизованный запрос releases/latest, несмотря на VERSION=1.19.6.

## Результат

- Bootstrap BASH_ENV для точного запроса официального action `curl -sf https://api.github.com/repos/anomalyco/opencode/releases/latest` отдаёт закреплённый tag v1.19.6 локально. Это ключ cache той же версии, которую уже требует installer и runtime guard.
- Все остальные curl-вызовы исполняются исходной программой с неизменёнными аргументами. Сеть installer, авторизация App, ограничения инструментов и проверка реальной версии сохраняются.
- Описание версии в документации отражает локальное разрешение cache key. Обязательный workflow Hexlet неизменен.
- Разовые пробы точной команды action без сети и делегирования других аргументов; существующий полный mise run check и независимые Standards/Spec. Постоянные тесты не добавляются.

Объём согласован делегированным поручением пользователя на полное завершение шага 3. Само поле темы не реализуется.
