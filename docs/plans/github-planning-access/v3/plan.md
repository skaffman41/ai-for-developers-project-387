# Очередь только допущенных команд

Основание: #12, полное поручение завершить шаг 3. Запуск публикации 44135735084 был отменён без jobs: пока обычная команда #17 выполнялась, publish ожидал в общей workflow concurrency-группе, а ответ бота создал новый запуск и вытеснил ожидающую команду. Повтор отменённого запуска восстановил публикацию, но причина остаётся.

## План

- Перенести существующую concurrency-группу с уровня workflow на job answer, после authorize. Недопущенные комментарии не входят в очередь исполнения; допуск остаётся до checkout и секретов.
- Сохранить прежний ключ по репозиторию и Issue/PR, cancel-in-progress false и timeout30. Один активный ответ на Issue; работающий ответ не отменяется. Обычное ограничение GitHub на один pending не меняется.
- Обновить описание очереди. Не менять права, модель, runtime, приложение, workflow Hexlet.
- Разовая структурная проверка: authorize без concurrency, answer после допуска с прежней concurrency. Полный существующий check, Standards/Spec. Новых автотестов не добавлять.

Объём — исправление обнаруженного препятствия к выполнению уже согласованного графа. Пользователь делегировал завершение задачи целиком.
