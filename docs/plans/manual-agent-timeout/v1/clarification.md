# Ручной запуск агента: 60 минут

Контекст — [#25](https://github.com/skaffman41/ai-for-developers-project-387/issues/25).
Владелец 18 ноября 2026 попросил сохранить `implement-spec #17` с графом
#19 → #20, перенести разработку недостающих тестов в следующую `/oc`-итерацию
и увеличить время ручного запуска. Уточнение записано в
[согласовании итераций](https://github.com/skaffman41/ai-for-developers-project-387/issues/12#issuecomment-6978797018).

## Объём

1. Увеличить только `jobs.answer.timeout-minutes` в `opencode.yml` с 30 до 60.
2. Проверить новое значение в существующем тесте workflow и обновить документацию.
3. Сохранить лимиты авторевью и triage 30 минут, reporter 5 минут, бюджет PR 3,
   допуск, очередь, права, секреты, pins и обязательный полный `mise run check`.

Эта правка не реализует универсальный runtime и функциональность календаря.
Исторические снимки планов остаются неизменными. Увеличение вступит в силу
после отдельной разрешённой интеграции в `main`; открытый PR не меняет bootstrap.

## Проверки и завершение

Существующая проверка ручного workflow должна сначала показать отказ на 30,
затем пройти на 60. Выполнить связанные проверки review/reporter, полный
`mise run check`, проверить diff и неизменность `hexlet-check.yml`.
Локальная проверка YAML не подтверждает фактический часовой запуск GitHub Actions.
Решение о публикации и merge остаётся за владельцем.

Откат — отдельный коммит, возвращающий 30 минут и прежний ожидаемый результат
проверки. Данные приложения эта правка не меняет.
