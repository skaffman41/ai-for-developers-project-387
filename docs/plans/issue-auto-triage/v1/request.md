Новые обращения автоматически получают предварительный разбор агента с учётом приложения и вопросами по недостающим условиям. Подготовленные тикеты повторно не разбираются.

- [ ] До checkout и секретов проверяются доверенный автор `skaffman41` типа User, инициатор и целевой репозиторий.

- [ ] README объясняет автотриаж, фильтры и ограничения; обязательный workflow Hexlet сохранён.
