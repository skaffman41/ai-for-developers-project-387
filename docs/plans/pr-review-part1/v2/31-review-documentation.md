## Результат

1. README: новый раздел «Автоматическое ревью PR и бюджет запусков» — события ревью, доверенный допуск (включая обязательную проверку PR OpenCode App), read-only сессия и публикация без модели, бюджет 3 ручных запуска на PR и источник состояния, no-model reporter, браузерная job проверки версии, ссылки на REVIEW.md и шаблон PR; обновлён обзор в разделе «Агент в GitHub».
2. `docs/agents/github-agent.md`: раздел об автоматическом ревью PR и бюджете — границы допуска, версия ревью и отмена устаревших, отсутствие прав записи истории Actions у токена агента, поведение reporter, режим `pr-review` подготовки runtime и его локальные проверки пробами debug.
3. `.github/workflows/README.md`: краткое описание `opencode-pr-review.yml` и изменений `opencode.yml`.
4. Обновление упоминаний в других документах только там, где прежний текст становится неверным (например, список workflow-разрешений); календарная документация и GLOSSARY не меняются.

## Критерии

- Все ссылки/якоря в обновлённых документах корректны; Prettier/линтер зелёные; `git diff --check` чистый.
- Документация не расширяет полномочия запусков и честно отделяет локально проверенное от живой приёмки.
- `hexlet-check.yml`, календарь, контракт и закреплённые версии не меняются.

## Testing Decisions

- Автотест не нужен: проверка линтера/форматирования и независимая проверка ссылок и якорей; содержательная сверка с реализованными workflow — самопроверкой по Review.md.
- Полный `mise run check` и две оси ревью по общим правилам.
